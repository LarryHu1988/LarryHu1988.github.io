## 滴水龙雨

生于滴水沿，现居滴水湖。生肖属龙，生时逢雨。

半导体行业从业十二年，从产品工程到工艺整合。

追梅西，忠巴萨，念科比。看读库，读新诗，写小诗。踢实况，打黑猴，码 APP。
